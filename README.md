# Portfólio Audrey R. Moura
Bem-vindo ao repositório do meu portfólio de design. Este projeto foi desenvolvido para exibir de forma dinâmica e interativa meus trabalhos em diversas áreas criativas.

#🛠 Tecnologias Utilizadas
- O portfólio é construído utilizando uma base de código clean, focada em performance e experiência do usuário:
- Linguagens: HTML5 e CSS3 (estilização e estrutura) e JavaScript (interatividade e lógica de interface).
- Fontes: Google Fonts - Poppins (implementada via @import e carregamento global).
- Ícones: Font Awesome 6.4.0 (via CDN para otimização).
- Design de Interface:
- Uso de variáveis CSS (:root) para gestão de temas e cores.
- Uso de clamp() para tipografia responsiva.
- Animações customizadas para efeitos de Glitch, Bounce e transições suaves.
- Implementação de Mockups de navegador (CSS puro) e sistemas Kanban (estilo Trello) para exibição de estratégias.
